and type-level programming.

`type-plus` declares `typescript` as a peer dependency and supports **TypeScript 5.6 and
above**. See [TypeScript version compatibility](/type-plus/guides/typescript-version-compatibility/)
for the versions covered by the test matrix.

## Your first utility type

Most of `type-plus` is types, so nothing needs to be imported at runtime:

```ts
import type { IsEqual } from 'type-plus'

type A = IsEqual<'a', 'a'> // true
type B = IsEqual<'a', 'b'> // false
```

## Branching options

The predicate types share one convention: instead of collapsing to `boolean`, they let you
choose what each branch returns, and how the special types `any`, `never` and `unknown` are
treated:

```ts
import type { IsString } from 'type-plus'

type A = IsString<string>          // true
type B = IsString<number>          // false
type C = IsString<any>             // boolean — `any` is both
type D = IsString<any, { $any: 1 }> // 1 — unless you say otherwise
```

This is the single idea that makes the library composable. Read
[Type branching](/type-plus/api/type-branching/) next, then
[Options](/type-plus/reference/options/) for the full list.
